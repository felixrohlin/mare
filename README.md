# Maré

Offline counting and early maths app for kids aged 2 to 7. Spoken crab tutor, six activities (bubbles, count, quick look, more, add, take away), adaptive levels per child, English / Portuguese / Swedish / Dutch.

Live: https://felixrohlin.github.io/mare/

Open it on the phone, add it to the home screen, open it once online. After that it runs offline. Progress is stored on the device only.

After changing any file, bump `VERSION` in `sw.js` so installed copies update.
